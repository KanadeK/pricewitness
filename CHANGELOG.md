# Changelog

All notable changes are documented here. The project follows semantic versioning.

## [0.1.0] - 2026-08-08

### Added

- Bounded deterministic parser for simple, weighted, and multi-quantity grocery lines.
- Validated merchant-aware alias book with exact, contains, and glob matching.
- Decimal unit normalization for mass, volume, and count domains.
- Transactional SQLite evidence ledger with SHA-256 duplicate detection.
- Price-spike, package-shrink, basket-change, and unit-conflict analysis.
- Review queue for unmapped or ambiguous product shorthand.
- Self-contained HTML, deterministic JSON, and formula-safe CSV outputs.
- Integrity, arithmetic, foreign-key, and optional original-source verification.
- One-command synthetic demo, tests, CI, reproducible packages, checksums, and SBOM.
