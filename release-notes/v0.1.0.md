# PriceWitness v0.1.0

PriceWitness turns grocery receipt text into a local, reviewable unit-price history. This first release ships a real post-OCR evidence pipeline rather than an empty interface.

Highlights:

- generic parser for packaged, weighted, and multi-quantity lines;
- merchant-aware alias mapping with explicit review/ambiguity states;
- mass, volume, and count normalization;
- price spike, shrinkflation, and personal basket signals;
- SQLite evidence ledger and optional original-file SHA-256 verification;
- offline HTML, JSON, and formula-safe CSV;
- a one-command synthetic demo;
- wheel, source distribution, deterministic demo ZIP, CycloneDX SBOM, and SHA-256 manifest.

Run the release demo after installing the wheel:

```bash
pricewitness demo --output .demo
pricewitness verify .demo/pricewitness.db \
  .demo/receipts/receipt-2026-01-12.txt \
  .demo/receipts/receipt-2026-03-18.txt \
  .demo/receipts/receipt-2026-07-30.txt
```

All bundled receipt data is synthetic. PriceWitness makes no market-price, CPI, legal, or financial claim.
